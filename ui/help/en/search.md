title: Finding a command
applies-to: [index]

Type what you want to do and kuulas shows the command, where it is in the menus and its key. Open **Help** and the cursor is already in the field "Search commands and help…" (or press {key:help.search}).

- Search by the name, by a word from its description, or by what you would call it elsewhere: "remove" finds Delete, "volume" finds Gain, "save as" finds Export. English and Finnish names both work, whatever language kuulas is in.
- The arrow keys choose a result and the confirm key runs it (the line under the results lists the keys). A greyed command stays in the list and says why it cannot run (for example, no project is open).
- The "Show in menu" button, or its key shown under the results, opens the command's own menu and highlights it, so you learn where it lives.
- Commands that are only in the command palette (the export for one format) say so. The palette ({key:palette.open}) searches the same way.
- Help topics that match are listed below the commands; click one to read it.
- In the desktop app the Help menu of the window's menu bar has "Search commands…", which opens the same search as a panel over the window.
