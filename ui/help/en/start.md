The start page lists the projects you opened lately, newest first.

- Open one: click it, or hold the modifier key shown on its row and press the row's number, 1 to 9, for the first nine. The chosen row lights up for a moment before it opens, so you can see which one it is. With reduced motion it stays still and just shows the outline.
- Remove from list: point at a row (or select it and press Delete) and use "Remove from list". A message offers Undo.
- A project whose folder was moved or deleted is marked "Not found", greyed and dashed. It cannot be opened; use "Locate…" to point to its new place, or remove it.
- File, Open Recent, "Remove missing projects from the list" removes all such entries at once, after one confirmation. "Clear menu" empties the whole list.

Removing only changes this list. The project folder and its recordings and files are never deleted, moved or changed. A project you removed can be opened again with Open project…
