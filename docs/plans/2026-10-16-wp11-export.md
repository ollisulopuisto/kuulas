# WP11 Export Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Export mixes, selections and aligned track stems in WAV, FLAC or MP3 with safe naming, repeatable settings, and mastering.

**Architecture:** Keep the shared audio math in `mixer.py`; render bounded blocks through an export module that owns file encoding, metadata, cancellation and cleanup. Persist remembered settings and export digests in project metadata, and expose the result through `Session` and the local HTTP API.

**Tech Stack:** Python, NumPy, soundfile, ffmpeg/libmp3lame, speechmix mastering, pytest.
