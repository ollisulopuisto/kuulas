# WP4 UI Shell and Timeline Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the translated browser editor shell and a responsive, navigable timeline backed by the WP3 API.

**Architecture:** Keep browser state in a small store, keep frame/time and coordinate math in pure modules, and isolate DOM, canvas, and API effects in view modules. Use the existing locale catalog and endpoint for every visible message, and let the server remain the source of project and transport state.

**Tech Stack:** Plain ES modules, Canvas 2D, browser APIs, Node's built-in test runner, Biome.

**Progress (2026-10-17):** Tasks 1-5 done on branch `wp4-ui-shell`; the draft was reviewed and mostly rebuilt (see the commit messages). Pure logic is in `view.js`, `lanes.js`, `waveform.js`, `ruler.js`, `keys.js`, `follow.js`, `wheel.js`, `edits.js`, `live.js`, `transport.js`, `tiles.js`, each with tests in `ui/tests/`. Waveforms are drawn in `waveform.worker.js` on an OffscreenCanvas.

**Verified in Chrome (2026-10-17):** two imported WAVs show two lanes with waveforms in the worker; click selects a clip and moves the playhead; Z switches to the 2 s close view around the pointer; F6/Esc cycle focus; a six-event slider drag sent two requests, one undo step, and no jump back; the toolbar shows "reconnecting" when the live channel is down. **Not verified:** Space playing audio (never started, by instruction); the playhead moving under live position messages (covered by `transport.test.js`, `store.test.js` with a fake engine only); drag-and-drop and the file picker in the browser (upload endpoint checked with curl); light mode.

**Open / decisions:** no project name in `/api/state`, so the toolbar shows none; the follow key, lane-height and waveform-height keys (Shift/Alt + =/-) and per-lane edge drag are WP5/WP6, toolbar buttons stand in; the samples level draws the finest 256-frame peaks stretched (no raw-sample endpoint); `uvicorn` ships without a WebSocket library, so `kuulas open` has no live channel until `websockets` is a dependency; Space-on-select opens nothing (Space always plays outside text fields).
