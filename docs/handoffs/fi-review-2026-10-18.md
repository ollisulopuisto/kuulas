# Finnish review of the strings added on 18 Oct 2026 (G14)

Scope: every key that did not exist this morning in `src/kuulas/locales/fi.json` —
759 keys (baseline: commit `08f40e7`, 17 Oct 23.56, the last fi.json change before
midnight) — read against the English in `en.json`. Nothing was edited; the owner
decides. Rows below list only strings with a real problem; everything else was
read and judged ok.

Checks run in addition to reading: `{placeholder}` sets compared programmatically
across all 759 (none lost, renamed or invented); `one`/`other` plural forms present
where English has them and used correctly; Finnish decimal commas (1,5 s) used
where English has 1.5; capitalisation and end punctuation compared with the
neighbouring keys. UI contexts that change a judgement were read in the code
(`ui/i18n.js`, `ui/keymap-config.js`, `ui/edit-plans.js`, `ui/inspector-track.js`,
`ui/clipboard-panel.js`, `ui/menu-model.js`).

The suggestions lean on the terms the older strings already use (`ui.clip.fade_in`
"Sisäänhäivytys", `ui.track.gain` "Raidan taso", `ui.track.solo` "Eristä raita",
`ui.view.close/wide` "Lähikuva/Yleiskuva", `ui.zoom.whole` "koko leikkaus",
`ui.transport.import` "Tuo ääntä", `key.shift` "Vaihto", `key.space` "Välilyönti",
`ui.focus.transcript` "Litteraatti", `ui.inspector.title` "Tarkastin").

## Other observations (not one key's fault)

- Hint verb person is mixed: some hints are imperative ("Mykistä valinta…",
  "Kopioi …"), most are third person ("Poistaa…", "Siirtää…"). This mirrors the
  mixed English; unify in `en.json` first if you want it uniform.
- Export hints mix "Tallentaa" and "Lataa" mirroring "Saves"/"Downloads"
  (cmd.export.narration_script_* say Lataa).
- Four keys that existed before today also use English-style “…”:
  error.server.missing_field, history.restored, history.correct_word,
  error.spot.invalid — same unification question as section 9.
- `ui.export.placeholders_skipped` "Se on hiljaista tässä viennissä." is mildly
  odd ("hiljainen"/"hiljaiseksi" would be predicative); left out of the table
  as borderline.
- Everything else in today's 759 — the candidates, markers, history, import,
  inspector, help, keymap, speed and transport strings, CLI help texts — read
  naturally and consistently; several are excellent ("Vapauta Vaihto: roll.",
  "Raidat pysyvät sovitettuina ikkunaan.", the whole ui.history.* set).
